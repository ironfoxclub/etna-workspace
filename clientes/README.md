# Clientes

Uma pasta por cliente: `clientes/<Nome>/`.

Dentro de cada uma:

- `CLAUDE.md` — quem é o cliente, o que ele vende, tom de voz e o bloco **Identidade visual**
  (cores, fontes, logo). É o que o Claude lê antes de criar qualquer coisa pra ele.
- o que mais o trabalho pedir (pesquisas, roteiros, peças, relatórios).

Material de cliente usa a identidade **do cliente**. A de `identidade/design-guide.md` é só da
sua empresa.
