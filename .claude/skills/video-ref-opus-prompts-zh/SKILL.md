## Quando usar

18 prompts completos e 54 casos públicos de "vídeo em código" com Opus 5.5, em chinês, com 9 rotas técnicas (Canvas, p5.js, Three.js, Remotion, Manim, Blender). Use para achar um prompt-base; traduza e adapte.

## Como usar

1. Veja se já existe um clone em `~/video-ia/opus-video-prompts`. Se não, clone raso: `git clone --depth 1 https://github.com/joeseesun/opus-video-prompts.git ~/video-ia/opus-video-prompts`.
2. Leia só o que precisa: `prompts/` (18 arquivos numerados), `cases.json` (casos com link do post original) e `README.md` (índice e dicas de escrita).
3. Não rode scripts de instalação ou de render do repositório sem ler antes e sem avisar o usuário (é código de terceiros).
4. Respeite a licença acima ao reaproveitar prompt ou código em material entregue; cite a fonte.
