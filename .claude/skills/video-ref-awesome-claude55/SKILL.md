Skill-índice: o repositório é uma coleção, não uma skill pronta. Ela só diz quando usar e onde ler.

- **Repositório:** https://github.com/athemeroy/awesome-claude-5-5-videos

## Quando usar

Catálogo de ~420 vídeos e projetos feitos com Claude 5.5 (Opus, Sonnet, Haiku, Fable), com padrões de produção e fluxos para fazer o seu. Use para estudar como um tipo de vídeo foi produzido e escolher o fluxo.

## Como usar

1. Veja se já existe um clone em `~/video-ia/awesome-claude-5-5-videos`. Se não, clone raso: `git clone --depth 1 https://github.com/athemeroy/awesome-claude-5-5-videos.git ~/video-ia/awesome-claude-5-5-videos`.
2. Leia só o que precisa: Comece por `README.md` (seção Make-your-own), `docs/library.md` (diretório por modelo) e `docs/README.md`. `data/` tem o índice. Os scripts em `scripts/` são de manutenção do catálogo: não precisa rodar.
3. Não rode scripts de instalação ou de render do repositório sem ler antes e sem avisar o usuário (é código de terceiros).
4. Respeite a licença acima ao reaproveitar prompt ou código em material entregue; cite a fonte.
