# video-ref-mg-styles-15

Skill-índice: o repositório é uma coleção, não uma skill pronta. Ela só diz quando usar e onde ler.

- **Repositório:** https://github.com/Vincentwei1021/mg-styles-15
- **Licença:** MIT
- **Categoria:** Vídeo

## Quando usar

15 estilos de motion graphics de 10 s, cada um com notas de estilo, prompt completo e código-fonte. Use para escolher um estilo de motion design e reaproveitar o prompt.

## Como usar

1. Veja se já existe um clone em `~/video-ia/mg-styles-15`. Se não, clone raso: `git clone --depth 1 https://github.com/Vincentwei1021/mg-styles-15.git ~/video-ia/mg-styles-15`.
2. Leia só o que precisa: `prompts/` (um prompt por estilo), `videos/` e `demos/` (resultado e fonte), `rubric.md` (critérios de qualidade), `template.md`. Atenção: o repositório é grande (mais de 1 GB com vídeos).
3. Não rode scripts de instalação ou de render do repositório sem ler antes e sem avisar o usuário (é código de terceiros).
4. Respeite a licença acima ao reaproveitar prompt ou código em material entregue; cite a fonte.
