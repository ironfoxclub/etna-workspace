# video-ref-awesome-opus55

Skill-índice: o repositório é uma coleção, não uma skill pronta. Ela só diz quando usar e onde ler.

- **Repositório:** https://github.com/yihui-dev/awesome-opus5-5-videos
- **Licença:** MIT
- **Categoria:** Vídeo

## Quando usar

Coleção com 700+ prompts reais e vídeos feitos pelo Claude Opus 5.5 escrevendo animação em código (HTML, Canvas, SVG, Three.js), por categoria. Use para achar o prompt-base de um estilo de vídeo (motion graphics, explainer, cena 3D) antes de pedir um vídeo novo.

## Como usar

1. Veja se já existe um clone em `~/video-ia/awesome-opus5-5-videos`. Se não, clone raso: `git clone --depth 1 https://github.com/yihui-dev/awesome-opus5-5-videos.git ~/video-ia/awesome-opus5-5-videos`.
2. Leia só o que precisa: Pastas `prompts/` (um .md por prompt) e `data/videos.json` (índice com link do post original). Procure com Grep por palavra do estilo (ex.: "explainer", "lineart") e adapte o prompt.
3. Não rode scripts de instalação ou de render do repositório sem ler antes e sem avisar o usuário (é código de terceiros).
4. Respeite a licença acima ao reaproveitar prompt ou código em material entregue; cite a fonte.
